Common .NET CLI Commands
1. Create a Console Application
Creates a new console (terminal) application.
Bash
dotnet new console
2. Create a Web API Project
Creates a new ASP.NET Core Web API project.
Bash
dotnet new webapi
3. Build a Project
Compiles the project and checks for errors without running it.
Bash
dotnet build
4. Run a Project
Builds and starts the application.
Bash
dotnet run
5. Create a Solution File
Creates a new .sln (solution) file used to organize one or more projects.
Bash
dotnet new sln
6. List Available Templates
Displays all project templates installed on your system.
Bash
dotnet new list
